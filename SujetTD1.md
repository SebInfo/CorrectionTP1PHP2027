# TP de révision PHP — BTS SIO SLAM

Ce dépôt contient une série d'exercices progressifs permettant de revoir les principales notions de PHP étudiées en première année avant d'aborder la suite du programme.

## Contenu du TP

1. **Variables, constantes et calculs**
2. **Conditions**
3. **Boucles**
4. **Tableaux et `foreach`**
5. **Fonctions**
6. **Formulaires PHP**
7. **Sécurisation des données**
8. **MySQL, PDO et requêtes préparées**
9. **Lecture et écriture de fichiers**
10. **`include` et `require`**
11. **Mini-défi de synthèse : catalogue de produits**

## Notions travaillées

- variables et constantes ;
- conditions et boucles ;
- tableaux associatifs ;
- fonctions ;
- formulaires et `$_POST` ;
- `isset()`, `trim()` et `htmlspecialchars()` ;
- connexion MySQL avec PDO ;
- requêtes SQL et requêtes préparées ;
- lecture et écriture de fichiers ;
- organisation d'une application avec `include`, `require` et `__DIR__`.

## Base de données

Les exercices PDO utilisent une base de données nommée :

```text
boutique
```

avec une table principale :

```text
produit
```

Le fichier de connexion utilisé est :

```text
connexion.php
```

## Objectif

À la fin du TP, vous devez être capable de réaliser un petit programme PHP procédural comprenant :

```text
Formulaire HTML
      ↓
     PHP
      ↓
     PDO
      ↓
    MySQL
      ↓
Affichage HTML
```

## Consigne

Réalisez les exercices en vous appuyant d'abord sur vos cours, vos anciens TP et la documentation PHP.

L'objectif est de retrouver les automatismes de programmation avant d'aborder les notions de deuxième année.
